# ADR-0001. 

- **Статус: принято**
- **Дата: 05-10-2026**

## Контекст

Для TimeCapsule необходимо регулярно доставлять изменения PHP-приложения на EC2-сервер в AWS. Исходный код хранится в GitHub. Приложение развёрнуто на одном EC2 и работает через nginx, PHP-FPM и PostgreSQL.

Нужно выбрать простой способ обновления приложения, который подходит для учебного проекта и позволяет сохранять историю изменений в Git.

## Решение

Используем Amazon Linux 2023.
Используем ручной деплой через `git pull` на сервере.

После отправки изменений в GitHub с помощью `git push` выполняется подключение к EC2 по SSH. На сервере выполняются:    

```bash
git pull --rebase
composer install --no-dev --optimize-autoloader
php bin/init-db.php
sudo systemctl reload php-fpm
```

## Рассмотренные альтернативы

### Копирование через scp
Файлы приложения можно было бы копировать с локального компьютера непосредственно на EC2 с помощью scp.
От этого варианта отказались, потому что при таком подходе GitHub не используется непосредственно для доставки кода на сервер, а история изменений и контроль версий отделены от процесса деплоя. Кроме того, при копировании необходимо самостоятельно следить за тем, какие файлы нужно передать.

###  Ручной git pull
Этот вариант выбран.
После git push изменения появляются в GitHub, а сервер получает их командой git pull. Способ простой, понятный и подходит для одного EC2-сервера и учебного проекта.
